# 🏗️ Stroyka - Интернет-магазин строительных материалов

## 🚀 Быстрый запуск Backend API

### Самый простой способ (рекомендуется):
1. Перейдите в папку `backend`
2. Дважды кликните по файлу **`START_HERE.bat`**
3. Сервер запустится автоматически

### Или через PowerShell:
```powershell
cd backend
.\START_HERE.bat
```

## 📚 API Документация

### Health Check
```
GET http://localhost:3001/health
```
Возвращает статус сервера:
```json
{
  "status": "OK",
  "message": "Stroyka API работает",
  "timestamp": "2026-11-08T20:22:45.123Z"
}
```

### Получить все товары
```
GET http://localhost:3001/products
```
Пример ответа:
```json
{
  "count": 3,
  "products": [
    {
      "id": 1,
      "name": "Цемент М500",
      "price": 450,
      "category": "Стройматериалы"
    },
    {
      "id": 2,
      "name": "Кирпич красный",
      "price": 25,
      "category": "Стройматериалы"
    },
    {
      "id": 3,
      "name": "Доска обрезная",
      "price": 850,
      "category": "Пиломатериалы"
    }
  ]
}
```

### Получить товар по ID
```
GET http://localhost:3001/products/{id}
```
Пример: `http://localhost:3001/products/1`
```json
{
  "id": 1,
  "name": "Цемент М500",
  "price": 450,
  "category": "Стройматериалы"
}
```

## 🛠 Техническая информация

### Backend API:
- **Технологии**: Node.js + чистый HTTP сервер
- **Порт**: 3001
- **Зависимости**: Нет внешних зависимостей
- **Особенности**: 
  - CORS включен
  - JSON формат ответов
  - Автоматический запуск браузера
  - Кликабельные ссылки в консоли

### Фронтенд (React):
- Расположен в папке `src/`
- Использует API с порта 3001
- Готов к интеграции с backend

## 🚨 Устранение проблем

### Порт 3001 занят
```bash
# Windows
netstat -ano | findstr :3001
taskkill /PID [PID] /F
```

### Сервер не запускается
1. Закройте все терминалы
2. Запустите скрипт от имени администратора
3. Убедитесь что Node.js установлен (`node --version`)

### Node.js не установлен
1. Скачайте Node.js с [nodejs.org](https://nodejs.org/)
2. Установите LTS версию
3. Перезапустите скрипт
